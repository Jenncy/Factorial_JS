# Calculadora de Factorial

Aplicación de escritorio desarrollada en C# y Windows Forms para calcular el factorial de un número.

## Funcionalidades

- Ingreso y validación de un número
- Cálculo del factorial
- Presentación del resultado

## Tecnologías

- C#
- .NET
- Windows Forms

## Ejecución

Abre la solución en Visual Studio, compila y ejecuta el proyecto.
